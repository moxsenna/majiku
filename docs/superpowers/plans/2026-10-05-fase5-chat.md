# Fase 5: Chat Parent↔Tutor (Messaging Nyata) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Komunikasi 1-on-1 nyata antara orang tua dan tutor: daftar percakapan, kirim/terima pesan dengan polling, unread count — menggantikan halaman mock `/parent/chat` dan `/tutor/chat`.

**Architecture:** Dua tabel baru (`conversations` unik per pasangan parent↔tutor, `messages`). Semua akses via server actions `src/server/actions/chat.ts` dengan authz participant-only. Realtime pragmatis: TanStack Query `refetchInterval` (8 detik saat jendela chat aktif, 30 detik untuk daftar percakapan). WebSocket/Durable Objects ditunda (YAGNI). Komponen chat dibuat sekali, dipakai kedua role via props `role`.

**Tech Stack:** Next.js 15, Drizzle + Neon, TanStack Query v5 (refetchInterval), shadcn/ui, date-fns id.

## Global Constraints

1. npm saja; branch `feat/fase5-chat` dari `main`; work in `D:\Coding\happy-days`.
2. Authz: hanya **participant** percakapan (parentUserId ATAU tutorUserId = session.user.id) boleh membaca pesan & mengirim; unauth read `[]`, mutation throw. Tidak ada chat lintas role lain di fase ini (admin tidak ikut chat v1).
3. Skema (satu-satunya perubahan DB):
   - `conversations`: id (text pk), `parentUserId` fk user cascade notNull, `tutorUserId` fk user cascade notNull, `studentId` fk students set null (konteks anak — nullable), `lastMessageAt` timestamptz, timestamps; **unique (parentUserId, tutorUserId)**.
   - `messages`: id (text pk), `conversationId` fk conversations cascade notNull, `senderUserId` fk user cascade notNull, `body` text notNull (trim, max 2000 — throw), `readAt` timestamptz nullable, createdAt; index pada conversationId + createdAt.
4. Pesan TIDAK bisa diedit/dihapus dari UI (YAGNI). Tidak ada attachment di chat v1.
5. Unread = messages WHERE readAt IS NULL AND senderUserId != session.user.id.
6. Polling: `refetchInterval: 8000` untuk messages percakapan aktif, `30000` untuk daftar percakapan; matikan saat tab tidak fokus (`refetchIntervalInBackground: false`).
7. UI mock lama (ParentChat/TutorChat) diganti props-driven; struktur visual (header, bubble kiri/kanan, avatar) dipertahankan.
8. Behavior halaman lain tidak berubah. Admin `/messages` tetap mock (catat di verification doc).

### Task 1: Skema + server actions chat

**Files:** Modify `src/db/schema.ts` (+2 tabel, migrations), Create `src/server/actions/chat.ts`.

**Interfaces (dipakai T2/T3):**
```ts
listMyConversations(): Promise<ConversationSummary[]>
// role-aware: parent → WHERE parentUserId = session; tutor → WHERE tutorUserId = session; lainnya/unauth → []
// ConversationSummary = { id, partnerName, partnerUserId, studentName: string|null, lastMessageBody: string|null,
//   lastMessageAt: Date|null, unreadCount: number } (LEFT JOIN messages terbaru + hitung unread; JOIN user & students utk nama)

getChatPartners(): Promise<ChatPartner[]>
// parent → tutor yang mengampu kelas anaknya (student_enrollments→classes→tutor_class_assignments→tutors JOIN user, DISTINCT, tutors.isActive)
// tutor → orang tua dari siswa di kelas yang diampu (arah sebaliknya, DISTINCT parent_user_id non-null)
// ChatPartner = { userId: string; name: string; role: "tutor"|"parent"; contextName: string } // contextName = nama kelas/anak

startOrGetConversation(partnerUserId: string, studentId?: string): Promise<{ id: string }>
// parent|tutor; validasi partner valid untuk role pemanggil (harus ada di getChatPartners hasil; kalau tidak throw "Tidak dapat memulai percakapan dengan pengguna ini")
// cari unique pair; bila tidak ada INSERT (studentId bila diberikan)

getMessages(conversationId: string): Promise<ChatMessage[]>
// participant only (throw "Percakapan tidak ditemukan" bila bukan participant); ORDER BY createdAt ASC; join user name
// ChatMessage = { id, senderUserId, senderName, body, createdAt, readAt, isMine }

sendMessage(conversationId: string, body: string): Promise<{ id: string }>
// participant only; body trim wajib 1..2000 char (throw); INSERT; UPDATE conversations.lastMessageAt = now()

markConversationRead(conversationId: string): Promise<void>
// participant only; UPDATE messages SET readAt = now() WHERE conversationId AND senderUserId != session AND readAt IS NULL
```
